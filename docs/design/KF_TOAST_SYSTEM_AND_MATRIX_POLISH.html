One toast system, and the matrix polished

There are three confirmation patterns in the product today: a dark green pill with a progress bar, a full-width cream block with a Close button, and a white centred overlay with no chrome at all. Three shapes for the same job means every save feels like a different product. One system below, covering every action the Service Calendar takes.

The toast

Bottom centre, dark, one shape. Icon carries state, title says what happened, second line carries the detail worth reading. Auto-dismisses after five seconds, pauses on hover, dismissible by click. Anything that needs a decision is a dialog, not a toast - a confirmation never has a Close button, because a message you must dismiss is not a confirmation, it is an interruption.

What this replaces, and the two calls inside it

  • The cream "No service recorded" block goes. It was a full-screen dialog doing a toast's job, and it made the smallest action in the product feel like the largest. It also demanded a click to dismiss for a message that needs no decision.
  • The white centred overlay goes. Covering the page to report a success blocks the next entry, which is exactly what a chef is about to do.
  • Undo replaces Close. Where the old pattern asked you to acknowledge, the new one offers the only thing you might actually want - to take it back. On the actions that can be taken back.
  • "4 days in - nice haul" becomes "4 days saved". My call, and worth disagreeing with if you like the warmth. The joke lands once and grates on the hundredth save, only one of the three current toasts has any personality so it reads as random rather than characterful, and it does not scale - there is no version of it for one day or for twenty-eight. The green check and the progress bar carry the satisfaction; the copy stays out of the way.
  • Progress belongs to bulk only. A month-completion bar on a single-day save is noise; on a four-day batch it is the answer to "how much is left".

The matrix, polished

The structure is right. What makes it feel unfinished is grid weight: borders on all four sides of every cell turn a summary into a spreadsheet, and the group rows fill only part of the width so the table looks misaligned even when it is not.

What changed in the matrix

  • Vertical rules gone. Columns are held by alignment, not by lines. This is the single biggest change - it turns a spreadsheet back into a summary.
  • Row rules lightened to the faintest tier, and the service column loses its boxed border so the first column reads as a label, not a cell.
  • Group rows span the full width including the service column. Currently the fill stops short, which is what makes the table look misaligned.
  • Dollar signs restored on the Total row. Two adjacent all-numeric rows where one is counts and one is money genuinely need the disambiguator - this is the exception to the drop-the-dollar-signs rule, not a contradiction of it.
  • The outlier tint gets a rounded fill rather than a full-bleed cell background, so it reads as a marked value rather than a broken row.
  • The batch hint moved next to the buttons it describes. "Saves as one batch, all 4 or none" is a consequence of pressing Confirm, so it belongs beside Confirm, not stranded above the note field.
  • Day headers keep the two-line stack - weekday over date reads faster than "Wed 19" on one line, and it was already right.
