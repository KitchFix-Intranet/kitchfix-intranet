What changed

  • Intranet shell — navy header, status flag, fact table, one button. Same as the invoice notifications.
  • Roughly half the words. The consequence is one sentence; the instructions moved into the footer.
  • Slack is a monitoring line for Kevin only — no @ mentions, since the site leaders aren't in that channel. The person chased is named as plain text. Both stages post.

    • Recipients — all derived from Postgres

  • Sunday goes to the account's salaried list — every salaried manager on the site, in the To field. No RDO on Sunday, so an email from the ladder means something needs the site's attention.
  • Monday adds Sebastian, Kevin, and the RDO to the salaried list. All primary — no Cc split.
  • The Slack line names one person — whoever last entered counts, or the site leader if nobody has, or the first name on the salaried list. That name is the Slack scalar only; the email To field is always the whole salaried list.
  • The RDO derives from the account's region — nobody maintains a list, and a new manager joins the chase when Rippling syncs them.
  • A departed employee can't be emailed — the address is checked against active staff first.
