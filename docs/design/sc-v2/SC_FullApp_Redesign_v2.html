Honest notes before you fall in love. (1) These are direction renders - real data shapes will stress them (a 40-service TBR day, a season with 300+ notes) and the build must survive that, not just this happy path. (2) The rail costs ~336px; at the 1280px matrix minimum the content pane still gets ~830px, which fits - but it should collapse below that. (3) Killing the hero banner and relocating the season summary/export into the rail are real IA decisions, not just paint. (4) Nothing here touches the engine - same views, same round-then-sum, same save paths; this is presentation over the data you already trust, same as Entry v2. (5) If you love it, this becomes an SC Redesign program: the Entry v2 scope you already have is one phase, and I'd write the sibling scope for the overview/drill/MLB surfaces with the same reuse-inventory + phased flag-guarded plan before CC touches anything.
