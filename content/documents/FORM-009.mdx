# Knife Skills Verification

The record that an employee has demonstrated safe knife technique. Once verified, the cut-resistant glove is recommended for routine knife work; until verified, it is required. A satellite of PB-007 Workplace Safety Manual.

# WHAT THIS IS

## What This Is

A competency check the Executive Chef completes to confirm an employee handles knives safely - and the record that gates the cut-resistant-glove rule.

KitchFix's cut-resistant-glove standard is competency-based. A trained, verified cook may work routine knife stations without a cut glove if they choose; an employee who has not been verified wears one until they are. This form is the verification. The Executive Chef observes the employee, checks each competency, and both sign. The signed copy is kept in the employee's training record in Rippling.

> CRITICAL: Regardless of verification, the cut-resistant glove is mandatory for everyone, every time, on these high-risk tasks: the mandoline, the slicer, deboning, shucking oysters or shellfish, and cleaning any slicer or food-processor blade. Skill does not protect you on a mandoline - speed and complacency are the risk.

- **Until verified, the glove is required** - a new or unverified employee wears the cut-resistant glove on the guiding hand for all knife work until this form is on file.
- **Once verified, it is recommended** - a verified employee may work routine knife stations without the glove. KitchFix still recommends it.
- **The high-risk tasks are always mandatory** - the list above never becomes optional, verified or not.

# THE VERIFICATION

## Knife Technique Competencies

The Executive Chef observes the employee at the board and marks each competency. Any "Needs work" means the employee is not yet verified - they keep wearing the glove and re-check after coaching.

| Check item | Pass | Needs work | N/A | Corrective action |
|---|---|---|---|---|
| Grip & control - pinch grip on the knife, claw/guiding hand on the food, fingertips tucked. |  |  |  |  |
| Stable workstation - board secured with a damp towel; always cuts on the board, never in the hand. |  |  |  |  |
| Cutting away from the body with a controlled, deliberate motion. |  |  |  |  |
| Knife sharpness - keeps a sharp edge, hones correctly, recognizes and reports a dull or damaged knife. |  |  |  |  |
| Selects the right knife for the task. |  |  |  |  |
| Safe carrying - tip-down, blade back, against the leg, and calls "KNIFE" when moving. |  |  |  |  |
| Safe passing & placing - sets a knife flat, handle out, away from the counter edge; never passes blade-first. |  |  |  |  |
| Never reaches for a falling knife - steps back and lets it land. |  |  |  |  |
| Cleans knives safely - washed separately, edge away, never left in a sink or soapy water. |  |  |  |  |
| Maintains control at working speed, not only at slow demonstration speed. |  |  |  |  |
